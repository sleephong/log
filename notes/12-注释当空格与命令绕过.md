# 12 · 注释当空格（`/**/`）与命令绕过

> 状态：✅ 已在**本机 PHP 5.4 实测通过**（`php -l` 无语法错误）+ bash 实测
> 来源：`comment-as-space` 实测脚本（`php_test.php` / `shell_test.sh`）

---

## 一、结论（一句话）

**`/**/` 能不能当空格，取决于「这个语言是不是按 token 解析」：**

- **按 token 解析**的语言（PHP / MySQL / JS）→ ✅ **可以**，注释在词法层等价于空白分隔符。
- **字符串字面量内部** → ❌ **不可以**，`/**/` 只是普通字符，长度照算。
- **对面是 shell** → ❌ **不可以**，shell 的注释符是 `#`，`/**/` 只是普通参数字符。

---

## 二、分场景对照表

| 场景 | `/**/` 能否当空格 | 说明 |
|---|---|---|
| PHP 代码 | ✅ | 词法层识别为注释 → 视作空白 |
| MySQL / SQL 语句 | ✅ | 同上 |
| JavaScript 代码 | ✅ | 同上 |
| 字符串字面量内部（`"sys/**/nb"`）| ❌ | 只是 4 个普通字符 |
| HTML 输出 / 页面文本 | ❌ | 浏览器只当文本看 |
| bash / sh 命令行 | ❌ | `#` 才是注释符；未加引号时按 glob 展开 |
| 已加引号（`"cat/**/flag"`）| ❌ | 引号内一律字面量 |
| 正则 / 替换串 | ❌ | 那里是数据，不是代码 |

**判断口诀**：**看语言是不是按 token 解析；在引号里、或者对面是 shell，一律无效。**

---

## 三、PHP 实测（PHP 5.4 通过）

```php
$a = 1/**/+/**/2;            // 3
$b = strlen/**/("abcd");     // 4
$c = 5;
$d = $c/**/==/**/5;          // true
class T { const K = 42; }
echo T/**/::/**/K;           // 42
echo/**/"hi";                // hi
```

**字符串内部是反例**：

```php
$e = "sys/**/nb";
strlen($e);                  // 9（不是 5）
strpos($e, 'sys nb');        // false（找不到）
```

> ⭐ 所以「`/**/` 能当空格」只在**代码层**成立；一旦进了引号就失效。

---

## 四、Shell 实测（bash）：`/**/` 根本不是空格

```bash
echo a/**/b                  # 一个参数 a/**/b（未加引号时是 glob）
set -- a/**/b; echo $#       # 1 → 没被拆开
cat/**/flag.txt              # No such file or directory
eval "cat/**/flag.txt"       # 同上，eval 也救不了
```

bash 的注释符是 `#`：

```bash
echo a # b                   # 只输出 a，后面的被当注释
```

### 真正的「空格替代品」清单（命令注入常用）

| 替代手法 | 例子 | 备注 |
|---|---|---|
| `${IFS}` / `$IFS` | `cat${IFS}flag.txt` | **最常用** |
| 制表符 | `cat%09flag.txt`、`$'\t'` | URL 里用 `%09` |
| 重定向 | `cat<flag.txt` | 省掉空格 |
| 花括号展开 | `{cat,flag.txt}` | bash 特性 |
| 通配符 | `cat /flag*`、`/???/??t /flag` | 靠路径匹配 |
| 空变量拼接 | `a=$' '; cat${a}flag.txt` | |
| 空变量拼接 2 | `cat$9 flag.txt`（`$9` 为空）| |
| 引号 / 反斜杠拆分 | `c''at flag.txt`、`c\at flag.txt` | 拆关键字躲 WAF |

> 口诀：**shell 里没有「注释当空格」这回事，只有 IFS / 重定向 / 花括号 / 通配符。**

## 五、附带发现：WAF 双解析差异绕过（重要）

WAF 若这样过滤（**漏了 `/s` 修饰符**）：

```php
preg_replace('/\/\*.*?\*\//', '', $input);   // ⚠️ 没有 /s
```

| 输入 | WAF 过滤后 | 解释器（PHP）看到 |
|---|---|---|
| `sys/**/nb` | `sysnb`（被删掉，认为无害）| `sys nb` |
| `sys/*<换行>*/nb` | **原样保留**（`.` 默认不匹配换行）| **仍是注释** → `sys nb` |

**原理**：`.` 在没有 `/s` 时不匹配换行 → WAF 的正则匹配失败 → 不删；而 PHP 词法层照样把它当注释。
→ **过滤器和解释器对同一段字节理解不一致 = 绕过。**

**防守方**：正则加 `/s`；或直接拒绝含 `/*` 的输入；或统一在**归一化之后**再做检测。

---

## 六、一句话

> **`/**/` 只在按 token 解析的语言里（PHP/MySQL/JS）能当空白分隔符；引号里失效，shell 里完全无效（shell 要用 `${IFS}`、`cat<file`、`{cat,file}`、通配符）。**
> **顺带：WAF 的正则漏 `/s` 时，`sys/*换行*/nb` 可绕过。**
