# 一、信息收集（**CTF 第一步**）

> **口诀：先翻源码，再扫敏感文件。** flag 常藏在"开发者没想到你会看到"的地方。

## 1.1 网页源码

```
Ctrl+U → 看 HTML 注释 <!-- -->
```
**注释里常藏**：提示、隐藏文件名、base64 编码的数据、甚至 flag。

**⚠️ 浏览器渲染 ≠ 源码**，必须看原始 HTML。

## 1.2 robots.txt / sitemap.xml

```
http://target/robots.txt        ← 常列出 Disallow 的敏感目录
http://target/sitemap.xml       ← 列出所有页面
```

**⚠️ 但很多题的 robots.txt 是"模板"，路径全 404，别死磕。**

## 1.3 备份文件（**极高频**）

| 备份名 | 说明 |
|---|---|
| `www.zip` / `web.zip` / `backup.zip` | 整站源码 |
| `index.php.bak` / `.php.bak` | 源码备份 |
| `.swp` / `~` / `index.php~` | vim 编辑器残留 |
| `.DS_Store` | macOS 目录索引 |

**⚠️ 下载后先看魔数，后缀会撒谎**：
```
PK\x03\x04              → ZIP
Rar!\x1a\x07\x00        → RAR4
Rar!\x1a\x07\x01\x00    → RAR5
7z\xbc\xaf\x27\x1c       → 7z
\x1f\x8b                 → gzip
\x89PNG                 → PNG
```

**⚠️ `7zr.exe`（精简版）不支持 RAR5**，要完整版 `7z.exe`。

## 1.4 Git 泄露

```
/.git/config          ← 第一步，看存不存在
/.git/HEAD
/.git/logs/HEAD       ← 能看到所有 commit
```

**工具**：`GitHack`、`git-dumper`

**⚠️ `.git` 泄露能扒出**全部源码 + 历史 commit**（里面常有被删的密码/flag）。**

## 1.5 目录/文件爆破

**工具**：`dirsearch`、`御剑`、Burp Intruder

**常见路径**：
```
robots.txt  sitemap.xml  www.zip  .git  .svn  .DS_Store
index.php.bak  index.php~  flag.php  admin.php  config.php
/api/  /admin/  /upload/  /backup/
```

## 1.6 前端 JS（**找接口必看**）

```
F12 → Sources → 看 .js 文件
搜: fetch / axios / /api/ /url
```

**JS 里 JS 常硬编码接口路径**：
```javascript
fetch('/api/user/info')
axios.get('/api/messages')
```

**⚠️ 看 JS 的四种方式**：
```
① Ctrl+U → Ctrl+F 搜 "fetch"     ← 看内联 JS、注释 ⭐
② F12 → Elements → Ctrl+F
③ F12 → Sources                    ← 调试、格式化
④ F12 → Network → 点按钮           ← 看实际请求 ⭐
```

# 二、代码审计

> **本质：找"用户可控输入（source）"是否流到了"危险函数（sink）"，且中间**没被过滤**。**

## 2.1 高危函数清单（**看到就要警觉**）

| 类别 | 函数 |
|---|---|
| **命令执行** | `system` `exec` `shell_exec` `passthru` `popen` `` `命令` `` |
| **代码执行** | `eval` `assert` `create_function`；`preg_replace` 带 `/e` |
| **文件包含** | `include` `require` `include_once` `require_once` |
| **读文件** | `file_get_contents` `fopen` `readfile` |
| **写文件** | `file_put_contents` `unlink` |
| **SQL** | `mysqli_query` `PDO::query`（字符串拼接） |
| **上传** | `move_uploaded_file` |
| **反序列化** | `unserialize` |

## 2.2 输入来源（source）

```
$_GET  $_POST  $_REQUEST  $_COOKIE  $_FILES  $_SERVER
文件上传、XML 解析、反序列化串
```

## 2.3 两个审计方向

| 方向 | 做法 | 速度 |
|---|---|---|
| **source → sink** | 拿 `$_GET['x']` 追踪它流向哪 | 慢 |
| **sink ← source** | ⭐ **搜 `system(` `include(` `eval(` 等** → 看参数是否可控 | **快** |

## 2.4 审计四步

```
① 搜危险函数：grep system/eval/include/query/unserialize/move_uploaded_file
② 看它的参数：是否拼了用户输入
③ 看有没有过滤：addslashes/黑名单/白名单/preg_match，能否绕过
④ 构造 payload 验证
```

## 2.5 快速示例

```php
$id = $_GET['id'];
$sql = "SELECT * FROM users WHERE id=$id";     // source → sink: SQL 注入
mysqli_query($conn, $sql);
```
```php
$file = $_GET['file'];
include($file);                                 // sink: LFI / php://filter
```
```php
$cmd = $_GET['cmd'];
system($cmd);                                   // sink: 命令注入
```

## 2.6 面试常问

```
"给你一段代码，漏洞在哪？"
→ 说出 source→sink 和漏洞类型
→ 常见：include($_GET)、system($_GET)、SQL 拼接、eval($_POST)、
        unserialize($_GET)、上传无校验、== 弱比较
```

# 三、一句话

> **信息收集：先翻源码（Ctrl+U 看注释）、再扫敏感文件（备份/.git/robots）**。**代码审计：找"用户输入"怎么流进"危险函数"** —— **先背危险函数清单，再看参数是否可控、能否绕过过滤**。
