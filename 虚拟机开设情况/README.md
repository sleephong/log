# 虚拟机开设情况

> 为 CTF 练习搭建的隔离实验环境 · 建于 **2026-10-09**
> 宿主机：Windows 11 家庭版 25H2（Build 26200）· AMD Ryzen 9 8945HX（16 核）· 16 GB 内存
> 虚拟化平台：**VirtualBox 7.2.20 r175154**

---

## 为什么要单独开这个目录

CTF 练习需要一个**能随便折腾、坏了就回滚**的环境。直接在宿主机上做实验有三个问题：

| 问题 | 后果 |
|---|---|
| 靶机是**故意带漏洞**的 | 万一被拿下，宿主机跟着遭殃 |
| 装 Kali / 靶机 / 各种工具 | 污染宿主机，卸载不干净 |
| 图省事用桥接网络 | 带漏洞的靶机**直接暴露在家庭局域网**，同路由器的任何设备都能打它 |

所以先建一台 Windows 11 虚拟机做基座，后续再挂 Kali 攻击机和靶机，**全部关在 VirtualBox 的内部网络里**，与宿主机和家庭局域网物理隔离。

这个目录记录：**这台虚拟机怎么建的、踩了哪些坑、以后 CTF 靶场怎么搭**。

## 虚拟机现状

**名称 `Win11-Daily`** ｜ 位置 `D:\VMs\Win11-Daily\` ｜ 状态：可用 ✅

| 项目 | 配置 |
|---|---|
| 系统 | Windows 11 **专业版** Build 26300（25H2 / 26H2）简体中文 |
| 计算机名 | `WIN11-DAILY` |
| 登录账户 | 用户名 `dsh`（密码见本机文档，**不写入公开仓库**） |
| vCPU / 内存 | 6 核 / 6144 MB |
| 磁盘 | 80 GB 动态分配（当前实占 22.9 GB） |
| 固件 | UEFI + **Secure Boot 已启用** + **虚拟 TPM 2.0** |
| 显卡 | VBoxSVGA / 256 MB / 3D 加速 |
| 鼠标 | **PS/2**（⚠ 不能用 USB 平板，会导致关机死锁，见踩坑文档） |
| USB | 控制器已开启（可做 U 盘直通） |
| 网卡 1 | **NAT**（能上网，外部不可见） |
| 网卡 2 | **内部网络 `CTFLab`**（CTF 靶场专用隔离网段） |
| 剪贴板 / 拖放 | 双向 |
| Guest Additions | 7.2.20 已安装 |
| 基线快照 | `干净基线`（在**关机状态**下打的） |
| 激活状态 | 未激活（有水印，功能与安全更新正常，见下） |

**为什么选专业版而不是家庭版**：无人值守安装默认选的是家庭版（`imageIndex = 1`），我改成了专业版（`--image-index=4`）。
因为专业版多出**远程桌面服务端、组策略编辑器（gpedit）、BitLocker、域加入**——这些都是 Windows 域渗透靶场和多数学 Windows 题目的前提。
而且没有密钥时家庭版和专业版在激活上没有区别（都是未激活），所以**专业版严格更优，不多花一分钱**。

## 常用命令

```powershell
$vbm = 'C:\Program Files\Oracle\VirtualBox\VBoxManage.exe'

# 开机
& $vbm startvm 'Win11-Daily' --type gui

# 让客户机正常关机（约 15 秒）
& $vbm guestcontrol 'Win11-Daily' run --exe 'C:\Windows\System32\shutdown.exe' `
    --username 'dsh' --password '<密码>' -- /s /t 5

# 打快照（⚠ 必须先关机再打！）
& $vbm snapshot 'Win11-Daily' take "快照名"

# 回滚
& $vbm snapshot 'Win11-Daily' restore "干净基线"
& $vbm snapshot 'Win11-Daily' list
```

> ⚠️ **不要在运行中的虚拟机上打快照。**
> VirtualBox 对运行中的 VM 打快照会先保存 2 GB 内存状态（`.sav`），如果保存期间做了别的操作（比如关机），两个操作会撞车导致 VM 永久卡在 `stopping`，只能强杀进程。**先关机，再打快照。**

## 关于激活

没有产品密钥，虚拟机处于**未激活**状态：

| 限制 | 影响 |
|---|---|
| 右下角"激活 Windows"水印 | 观感问题 |
| 不能修改壁纸 / 主题 / 个性化 | 不影响使用 |
| **功能和安全更新** | **完全正常** |
| 日常使用、CTF 练习 | **完全不受影响** |

购买正版密钥后在「设置 → 系统 → 激活」输入即可激活。
**本方案未使用任何绕过激活的手段。**
