# L1-073 胎压监测

> 来源：PTA 2020 年团体程序设计天梯赛 L1-073 胎压监测（题面据公开题解整理，若有出入以 PTA 为准）
> 平台：PTA，gcc（C99）
> 通用语法见 [notes/19-C语言基础.md](../../notes/19-C语言基础.md)；打擂台与计数模式见该文件第 11 节。

## 一、题干

四个车轮顺次编号 1、2、3、4（左前、右前、右后、左后）。输入 6 个 [0, 400] 范围内的整数：1~4 号胎压、最低报警胎压 low、胎压差阈值 y。

报警规则：

| 情况 | 输出 |
|---|---|
| 所有胎压与"四胎最大值"的差都不超过 y，且都不低于 low | `Normal` |
| 恰好一个轮胎超差或低于 low | `Warning: please check #X!`（X 是该轮胎编号） |
| 两个及以上 | `Warning: please check all the tires!` |

官方样例：

| 输入 | 输出 |
|---|---|
| `242 251 231 248 230 20` | `Normal` |
| `242 251 232 248 230 10` | `Warning: please check #3!` |
| `240 251 232 248 240 10` | `Warning: please check all the tires!` |

注意第一组：`231` 低于最低值 `230` 吗？不低，等于不报警；`251-231=20` 超过阈值 `20` 了吗？没超过，等于不报警。所以这组是 Normal。边界都压在这两个等号上。

## 二、我的代码（原样）

```c
#include<stdio.h>
int main(){
    int p1,p2,p3,p4,low,y;
    scanf("%d %d %d %d %d %d",&p1,&p2,&p3,&p4,&low,&y);
    int max = p1,cnt = 0,pos = 0;
    if(p2>max)max=p2;
    if(p3>max)max=p3;
    if(p4>max)max=p4;
    if(p1<low||max-p1>y){cnt++;pos=1;}
    if(p2<low||max-p2>y){cnt++;pos=2;}
    if(p3<low||max-p3>y){cnt++;pos=3;}
    if(p4<low||max-p4>y){cnt++;pos=4;}
    if(cnt == 0)
        printf("Normal");
    else if(cnt == 1)
        printf("Warning: please check #%d!",pos);
    else
        printf("Warning: please check all the tires!");
}
```

## 三、逐段讲

`int max = p1, cnt = 0, pos = 0;`
    这行写在 `scanf` 之后，属于 C99 的"声明可以出现在语句之后"。gcc 编译没问题；C89（比如 VS2010 的 C 模式）会报错，必须把声明挪到块首。

`if(p2>max)max=p2;` 三行
    打擂台找最大值：先把 1 号胎压当擂主，2、3、4 号依次来挑战，赢了就换擂主。三行之后 `max` 就是四胎最大值。

`if(p1<low||max-p1>y){cnt++;pos=1;}`
    对 1 号轮胎单独判断：低于最低值，或者与最大值差超过阈值，就记一次并记下编号。

关键点：这四行是**四个独立的 if**，不是 `else if`。四个轮胎每个都要检查，条件之间不互斥。如果写成 `else if`，检查完第一个有问题的轮胎就跳出去了，后面的轮胎永远不会被发现，"两个及以上"那一支也就进不去。

`if(cnt == 0) ... else if(cnt == 1) ... else ...`
    按计数分三支。第三支用 `else` 兜底是对的：前面已经覆盖 0 和 1，剩下的就是 2 及以上（cnt 最多 4，不会为负）。

`pos` 每次命中都会覆盖
    因为只在 `cnt == 1` 时才用 `pos`，此时只可能命中过一次，所以覆盖不影响结果。这是对的，但也是本题最容易写错的地方，见第五节的第 2 条。

## 四、样例走查

| 输入 | 与最大值的差 | low 检查 | cnt | 输出 |
|---|---|---|---|---|
| 242 251 231 248 / 230 / 20 | 9, 0, 20, 3 | 231 >= 230，全部达标 | 0 | Normal |
| 242 251 232 248 / 230 / 10 | 9, 0, 19, 3 | 19 > 10，3 号超差 | 1 | #3 |
| 240 251 232 248 / 240 / 10 | 11, 0, 19, 3 | 1 号和 3 号超差 | 2 | all the tires |

第一组里 `20` 与阈值 `20` 相等，`>` 不成立，所以不报警；`231` 与 `230` 相等，`<` 不成立，也不报警。题目说"误差超过阈值"、"低于最低值"，都是严格不等号。

## 五、问题与改法

| # | 问题 | 说明 |
|---|---|---|
| 1 | 四个 `if` 是独立判断，写法正确 | 这里必须用独立 if，不能用 else if；能想到"逐个检查"说明题意读对了 |
| 2 | `pos` 依赖"只在 cnt == 1 时使用"才正确 | 常见错法是把 `if(cnt == 1) pos = i;` 写进循环体，后面的正常轮胎会把 pos 覆盖成自己的编号。正确做法就是像这样：命中就更新 cnt 和 pos，最后统一用 |
| 3 | 四段几乎一样的代码 | 现在没学数组，这样写可以接受；学了数组和循环之后，用 `tire[4]` + 一个循环就能压成 10 行 |
| 4 | `p1..p4` 这种命名 | 题目本身就是 1~4 号轮，问题不大；用数组后自然变成 `tire[i]` |
| 5 | 没有 `return 0;` | C99 隐式返回 0，不算错 |
| 6 | 输出末尾没有换行 | PTA 可以接受 |

## 六、参考写法

写法 A：数组 + 循环（学了数组以后回来看）

```c
#include <stdio.h>

int main(void)
{
    int tire[4], low, y;
    for (int i = 0; i < 4; i++) {
        if (scanf("%d", &tire[i]) != 1) {
            return 0;
        }
    }
    scanf("%d %d", &low, &y);

    int max = tire[0];
    for (int i = 1; i < 4; i++) {
        if (tire[i] > max) {
            max = tire[i];
        }
    }

    int cnt = 0, pos = 0;
    for (int i = 0; i < 4; i++) {
        if (tire[i] < low || max - tire[i] > y) {
            cnt++;
            pos = i + 1;          /* 题目编号从 1 开始，下标从 0 开始 */
        }
    }

    if (cnt == 0) {
        puts("Normal");
    } else if (cnt == 1) {
        printf("Warning: please check #%d!\n", pos);
    } else {
        puts("Warning: please check all the tires!");
    }
    return 0;
}
```

要点：编号与下标差 1，`pos = i + 1`；找最大值和计数各用一个循环，结构比四段复制清楚。

写法 B：不引入数组，只把打擂台写紧凑

```c
int max = p1;
max = p2 > max ? p2 : max;
max = p3 > max ? p3 : max;
max = p4 > max ? p4 : max;
```

三元运算符读起来比 `if` 更像一个表达式，但也更容易看错，习惯 `if` 就不用急着换。
