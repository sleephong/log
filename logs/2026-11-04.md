## 二、知识点

### 1. 探测全过程的九个阶段

| 阶段 | 动作 | 实测判据 |
|---|---|---|
| 0 基线 | 记状态码、长度、固定文案 | 长度 106，文案 `You are in` |
| 1 有无注入 | 单引号 | 长度 228，报错 `near ''1'' LIMIT 0,1'` |
| 2 真假对照 | `and 1=1` / `and 1=2` | 119 / 86，长度不同说明布尔可控 |
| 3 闭合符 | 读报错里的引号形态 | `''` → 单引号；`')` → 带括号 |
| 4 列数 | `order by N` | `order by 4` 报 `Unknown column '4'` → 3 列 |
| 5 回显位 | `union select 1,2,3`，参数写 `-1` | 页面出现 `2` → 第 2 列回显 |
| 6 环境 | `database()` / `version()` | 得到库名与版本 |
| 7 表名 | `group_concat(table_name)` + `where table_schema=database()` | 拿到表清单 |
| 8 列名 / 数据 | 同法，`0x2e` 拼库表、`0x3a` 拼字段 | 拿到列名与账号口令 |

**关键**：每一步只改一个变量，才能知道是哪一步断的。

### 2. 列名查询必须同时限定库名

只写 `where table_name='users'` 会命中**所有库**里叫 users 的表，结果里混进 `mysql.user` 的 `USER`、`CURRENT_CONNECTIONS`。

必须写成 `where table_schema='security' and table_name='users'`。

### 3. 二次注入：转义只管"写入"，不管"使用"

```php
// 写入：开发者以为安全了
$u = addslashes($u);
$pdo->exec("INSERT INTO users(username,password) VALUES('$u','$p')");

// 使用：用户名从库里取出，再拼进 SQL
$name = $row['username'];
$pdo->exec("UPDATE users SET password='$new' WHERE username='$name'");
```

实测：注册 `admin'#` → 库里存的就是 `admin'#`（反斜杠只是转义符，被 MySQL 消费掉）→
改密时拼成 `WHERE username='admin'#'` → `#` 注释掉后面的引号 → **改掉了 admin 的密码**。

换成预编译后，同样的输入只改到自己那一行，admin 不受影响。

**本质**：数据在"存储层"和"使用层"之间丢了一次保护。

### 4. `where` 被过滤时用 `if()` 替代

```sql
-- 原句
select group_concat(table_name) from information_schema.tables where table_schema='security'

-- 替代
select group_concat(if(table_schema='security',table_name,null)) from information_schema.tables
```

**原理**：`if` 让不匹配的行返回 `NULL`，而 `group_concat` 会跳过 `NULL`。

**实测反例**：第三个参数写成空串 `''` 时，结果变成一大串逗号——空串也会被拼接，只有 `NULL` 会被跳过。

### 5. `or` 与 `union` 不能直接相邻

```sql
WHERE id='0' or union select ...     -- 报错 1064
WHERE id='0' or (select ...)         -- 可用：子查询
WHERE id='0' or 1=1 union select ... -- 可用：中间有表达式
```

`or` 要的是**表达式**，`union` 要的是**完整查询**，中间缺操作数就报错。
另外 `union` 还要求**列数一致**，否则 1222。

### 6. `select` 与 `union select` 的根本区别

- `select` 是**语句**；`union select` 是**集合运算**，把两个结果集纵向拼接
- `union` 三个硬条件：列数相同、类型兼容、位置在回显位
- `union` 默认去重，`union all` 不去重
- `or` 后面是表达式位，`select` 必须加括号变标量子查询；`union` 后面是语句位，`select` 直接写

### 7. 弱比较的六组归类

值相等（`==` / 0e / 双哈希 / 科学计数法 / 八进制）、类型变空（数组绕过）、截断（`intval`）、返回值陷阱（`strpos` / `strcmp` / `preg_match`）、弱转换（`switch` / 布尔）、版本差异（PHP 8 收紧）。

补充项里最该记的三条：`in_array` 不传 strict、`empty("0")` 为真、`strncmp($a,$b,0)` 恒真。

## 四、踩坑

| 坑 | 现象 | 原因 / 解决 |
|---|---|---|
| `#` 注释吃掉行尾分号 | 多语句脚本里后一句粘连报错 | `#` 只到行尾，分号要另起一行；单请求场景不受影响 |
| SQLite 不认 `#` | `unrecognized token: "#"` | 注释符按方言换：SQLite 用 `--` |
| sqli-labs 跑不起来 | `Call to undefined function mysql_connect()` | 它用的是 PHP 5 的 `mysql_*`，PHP 8 已移除；改自写探针模拟 |
| 列名查询混库 | 结果里出现 `USER,CURRENT_CONNECTIONS` | 只限定 `table_name` 不够，必须加 `table_schema` |
| `if` 第三参写 `''` | `group_concat` 输出一堆逗号 | 必须写 `NULL`，空串会被拼接 |
| `or union` 直接相邻 | `ERROR 1064` | `or` 要表达式，`union` 要查询，中间必须有内容 |
