## 二、知识点

### 1. 两两异或的判据：白占比 + 结构度

N 张图里哪两张是一对？不能靠肉眼试，要有量化指标：

```python
z = cv2.bitwise_xor(a, b)
g = cv2.cvtColor(z, cv2.COLOR_BGR2GRAY)

white = np.mean(g > 127)                       # 白占比
same  = ((g[:, :-1] == g[:, 1:]).mean() +      # 横向相邻相同比例
         (g[:-1, :] == g[1:, :]).mean()) / 2   # 纵向相邻相同比例

rows.append((white, same, f1, f2))
rows.sort()                                     # 白占比低的优先
```

**原理**：两张**无关**的图异或后接近随机噪声，白占比 ≈ 50%、结构度 ≈ 0.5；**有信息**的一对会明显偏离——白占比偏低（大片黑底）、结构度高（有笔画/文字，相邻像素大量相同）。

**8 张图 = 28 对**，排序后前几名肉眼扫一遍就行，比一张张试快一个量级。

### 2. 同尺寸是异或的前提

异或要求两个数组形状一致。脚本里 `if a.shape != b.shape: continue`——尺寸不一致直接跳过，不然 numpy 会广播报错或产生误导结果。

**这也是一条线索**：附件里尺寸一致的那几张，才是候选。

### 3. 结果会被插画线条污染

这题的异或是"文字图 ^ 插画图"，出来的结果里文字和插画线条叠在一起。所以还需要：

- 放大（NEAREST 保像素，别用 LANCZOS 会糊）
- 裁出文字所在的条带
- 必要时反色（`255 - x`）看对比度

### 4. BMP 不方便直接看

`.bmp` 是无压缩位图，很多图片查看器/工具链对它的支持不一致（比如我这边读图接口只吃 PNG/JPEG/WebP/GIF）。**处理前先转 PNG**：

```python
from PIL import Image
Image.open("solved.bmp").convert("RGB").save("solved.png")
```

### 5. 抄 flag 要防"字符与线条重叠"

这张图里的 `/` 和插画斜线完全同角度、同粗细，肉眼分不清是字符还是画面。

**做法**：裁出文字带 → 放大 → 逐字符数宽度 → 拿不准就回平台校验，别硬抄。

### 复盘

**能做出来不等于能讲出来。** SSTILab 13 关全通，但被问"原理"时说不出"模板引擎会把 `{{}}` 编译成代码执行"——这就是被追打的原因：对方听到"我打过 13 关"，下一句必然是"那第 13 关怎么抠下划线的"。

**被追问时最该练的不是记更多 payload，是把每个点压缩成三句话**：机制是什么 → 为什么会产生这个现象 → 本质一句话。

例如 `.htaccess`：它就是 Apache 的目录级配置入口，本来就有权改解析规则，所以一旦目录可写，等于把配置权交出去了。
