### 关键结论（一句话版）

- **画圆题**：提示说的「js 文件」指 `circle.html` 的**内联 `<script>`**，`js/` 目录全是幌子。搜 `atob` 直接命中；触发条件（画出 100% 圆度的圆）是叙事包装，不是解法。
- **Perfect Waf**：WAF 只查 POST 的 `name` 字段、且只拦「以 `.php` 结尾」；Apache 只看文件名结尾决定是否解析。两套标准的空隙 = `xxx.jpg.php`。文件内容零过滤。
- **rce_me**：四层校验每层都是「两个看似矛盾的判断」，突破口都是**判定标准的差异** —— 嵌套 `if` 短路 / `sha1` 与 `md5` 松散比较 / `intval` 对科学计数法的两次转换 / 正则 `.+?` 与 `stripos` 的前置要求。最卡的是 L2 的键名带点号。

### 今日最大的知识点：PHP 参数名解析规则

源码里键名带点号（`$_POST["__2024.geekchallenge.ctf"]`）时**直接传不进去**。用**本机 PHP 5.4 起 `php -S` 实测**出规则：

```
规则① 参数名 **以 `[` 开头** → 整个变量被丢弃
规则② 有 **未闭合的 `[`** 时：`[` 之前的点号转 `_`，`[` **之后的点号不转换**
```

所以要拿到键名 `__2024.geekchallenge.ctf`，参数名必须是 `_[2024.geekchallenge.ctf`（`[` 恰好在第 2 位）。已整理进 [notes/01 §2.3](../notes/01-HTTP基础.md)。

### 顺带确认的事

- **GET / POST 不合并**：`start` 必须放 body，`year`/`purpose`/`code` 必须放 URL（靠 `$$key` 覆盖），**两部分要在同一次请求里**
- **本地杀软会隔离 exp 脚本**：源码含完整木马特征串 → Windows Defender 报毒删文件 → payload 改运行时拼装
- **base64 前缀速查**：`SYC{` → `U1lD`、`flag{` → `ZmxhZ`、`PKWCTF{` → `UEtXQ1RG`、`0xGame{` → `MHhHYW1l`
