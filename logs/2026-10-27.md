## 二、知识点

### 1. 总原则：先便宜后昂贵，先结构后像素

能用一条命令排除的就别开 GUI；文件层面能找的别动像素。理由是 Misc 的耗时分布极不均匀：魔数、元数据、尾部附加、编码这几层都是秒级，位平面和频域是分钟级。顺序错了，会在最容易的入口上耗光时间。

### 2. 魔数优先于后缀

```
89 50 4E 47    PNG
FF D8 FF       JPEG
42 4D          BMP
47 49 46 38    GIF
50 4B 03 04    ZIP / docx
```

后缀和魔数不一致就直接改后缀再拆。`06_假文件头.png` 就是 `.png` 的真身是 ZIP。

### 3. 九种手法，各自的第一判据

| 手法 | 判据（看到什么就该想到它） |
|---|---|
| tEXt 藏串 | `strings` 或 PNG 块里出现 `tEXt` / `iTXt` / `zTXt` |
| 尾部附加 | IEND 之后还有字节，或搜到 `PK\x03\x04` |
| LSB | 图片能正常打开、像素挨着看有噪点，扫描器命中 |
| 位平面 | 某个 bit 平面结构度异常（普通图接近 50% 随机） |
| FFT | 整幅图看不出东西，但频域有文字 |
| 假文件头 | `file` / 魔数 与后缀不符 |
| 改宽高 | 图"只有上面一半"、下半截空白或打不开 |
| 图像相减 | 给了两张几乎一样的图 |
| GIF 多帧 | 动态图、某些帧一闪而过 |

### 4. LSB 不是"扫一遍"，是组合空间

通道顺序（RGB / BGR）× 位序（MSB first / LSB first）× 位平面（bit0~bit2）× 起始偏移。只试一种写法很可能全空。扫描器里把这四维都铺开扫，命中时打印具体组合，这样下次就能直接按那个组合手工复现。

### 5. FFT 看图看"实部"，且不要 fftshift

```python
F = np.fft.fft2(gray)
np.real(F)              # 文字在左上 / 右上，镜像在右下
np.log1p(np.abs(F))     # 幅度谱用对数压缩，不然只有中心一点亮
```

`fftshift` 会把零频挪到中心，文字位置随之改变，反而对不上网上教程的坐标。

### 6. 修复层就三件事

| 症状 | 改哪里 |
|---|---|
| PNG 报 CRC 错 | 重算 IHDR 的 CRC |
| 图只有一半 / 下半截空白 | 改 IHDR 的 height（`07_改宽高.png` 把 600 改成 300） |
| 打不开 / 类型识别错 | 补正确魔数 |

改高度后图片能正常解码，是因为 PNG 按行存储：头部声明多少行就只解多少行，多出来的字节被当成尾部附加数据忽略。所以"改回真实高度"往往能直接看回下半截。

### 7. `.bat` 必须全 ASCII

`toolbox.bat` 里写中文注释会炸。cmd 按 OEM 代码页（简体中文是 936/GBK）读取批处理文件，UTF-8 的中文字节被当成控制字符，会导致 `goto` 标签错位、`set` 语句被截断。所以那个文件正文全用英文。`chcp 65001` 只改控制台的显示代码页，救不回按 OEM 代码页读进去的脚本内容——中文说明放 `.md`，别放 `.bat`。

### 8. 时间预算

| 阶段 | 预算 |
|---|---|
| 认文件 + 元数据 | 1.5 分钟 |
| 结构 / 嵌套 | 2 分钟 |
| 编码 | 1 分钟 |
| 位平面 + LSB | 3 分钟 |
| 视觉 | 2 分钟 |
| 频域 | 3 分钟 |
| 修复 | 2 分钟 |
| 合计 | 约 15 分钟，超了就换题 |

### 3. 尾部附加的手工验证

```python
d = open('02_尾部附加.png','rb').read()
i = d.find(b'IEND')
print('IEND 位置', i, '文件总长', len(d), '尾部', len(d)-i-8)
j = d.rfind(b'PK\x03\x04')
open('tail.zip','wb').write(d[j:])
```

### 4. 改高度

```python
import struct
d = bytearray(open('07_改宽高.png','rb').read())
w, h = struct.unpack('>II', d[16:24])
print('声明尺寸', w, h)
d[20:24] = struct.pack('>I', 600)      # 改回真实高度
```
