# 7-7 12-24小时制

> 来源：PTA 基础编程题目集 7-7 12-24小时制
> 平台：PTA，gcc（C99）
> 通用语法见 [notes/19-C语言基础.md](../../notes/19-C语言基础.md)；"按题面不按常识"见该文件第 12 节。

## 一、题干

输入 24 小时制的时间，输出 12 小时制的时间。

- 输入：一行 `h:m`，中间是半角冒号。小时或分钟小于 10 时**没有前导零**，比如 `5:6` 表示 5 点 6 分
- 输出：数字部分格式与输入相同，然后一个空格，再跟 `AM` 或 `PM`
- 两条约定：中午 12 点算下午，所以 `12:0` → `12:0 PM`；0 点算第二天，所以 `0:0` → `0:0 AM`

样例：`21:11` → `9:11 PM`

注意最后一条：英文习惯里 0 点常写成 `12:00 AM`，但**本题题面明确要求 `0:0 AM`**，按题面来。

## 二、我的代码（原样）

```c
#include<stdio.h>
int main(){
    int a,b;
    scanf("%d:%d",&a,&b);
    if(a<12)
        printf("%d:%d AM",a,b);
    else if(a == 12)
        printf("%d:%d PM",a,b);
    else
        printf("%d:%d PM",a-12,b);
}
```

## 三、逐段讲

`scanf("%d:%d",&a,&b);`
    格式串里的 `:` 不是占位符，是一个**普通字符**：输入里必须真有一个冒号，而且位置要对。如果输入写成 `2111`，`%d` 读完 2111 之后找不到冒号，第二个 `%d` 就读不到东西，`b` 保持定义前的状态（垃圾值）。

`if(a<12)` → `%d:%d AM`
    0 到 11 点都是上午。这里 `a = 0` 也落进这一支，输出 `0:0 AM`，正好符合题面的约定。

`else if(a == 12)`
    12 点必须单独拎出来，而且要输出 `12`。如果让它走 `a - 12`，结果会是 `0:0 PM`，错。

`else` → `a-12` PM
    13 到 23 点换算成 1 到 11 点。`a` 在这个分支里一定大于 12，所以 `a - 12` 至少是 1，不会出现 0 点。

`%d` 而不是 `%02d`
    题面要求"数字部分格式与输入的相同"，而输入本身不带前导零，所以用 `%d` 正好。要是用了 `%02d`，`5:6` 会输出成 `05:06 AM`，反而错了。

## 四、分支表

| 24 小时制 | 命中分支 | 输出 | 说明 |
|---|---|---|---|
| 0:0 | `a < 12` | 0:0 AM | 题面约定：0 点算第二天，不换算成 12 |
| 5:6 | `a < 12` | 5:6 AM | 分钟也不补零 |
| 11:59 | `a < 12` | 11:59 AM | 上午最后一分钟 |
| 12:0 | `a == 12` | 12:0 PM | 中午算下午，小时仍是 12 |
| 12:59 | `a == 12` | 12:59 PM | |
| 13:5 | `a > 12` | 1:5 PM | 小时减 12 |
| 21:11 | `a > 12` | 9:11 PM | 题面样例 |
| 23:59 | `a > 12` | 11:59 PM | 一天最后一分钟 |

## 五、问题与改法

| # | 点 | 说明 |
|---|---|---|
| 1 | 逻辑没有错 | 三个区间正好把 0~23 分完，12 点单独处理是对的 |
| 2 | `a == 12` 与 `a > 12` 都输出 PM | 可以合并成一处，PM 只写一次（见写法 B） |
| 3 | `scanf` 没检查返回值 | 输入格式不对时 `b` 是垃圾值。PTA 的输入固定，所以能过；但这是"格式串里的普通字符要原样匹配"的经典坑 |
| 4 | 没有 `return 0;` | C99 隐式返回 0，不算错 |

## 六、参考写法

写法 B：把 PM 合并，只判断"要不要减 12"

```c
#include <stdio.h>

int main(void)
{
    int h, m;
    if (scanf("%d:%d", &h, &m) != 2) {
        return 0;
    }

    if (h < 12) {
        printf("%d:%d AM\n", h, m);
    } else {
        printf("%d:%d PM\n", h == 12 ? 12 : h - 12, m);
    }
    return 0;
}
```

写法 C：先算 12 小时制的小时数，再判 AM/PM（最贴题面的结构）

```c
int hour12 = (h > 12) ? h - 12 : h;      /* 12 点不换算，0 点也不换算 */
printf("%d:%d %s\n", hour12, m, (h >= 12) ? "PM" : "AM");
```

要点：`h > 12` 才减 12，`h == 12` 保持 12，`h == 0` 保持 0。这正是题面那两条约定决定的，换成"英文习惯"的版本就得改成 `h % 12 == 0 ? 12 : h % 12`，但那样 0 点会变成 12:00 AM，本题会判错。
