> 来源：PTA 团体程序设计天梯赛练习集 L1-075 强迫症（题面据公开题解整理，若有出入以 PTA 为准）

> 通用语法见 [notes/19-C语言基础.md](../../notes/19-C语言基础.md)；拆位与定宽输出见该文件第 10 节。

## 一、题干

小强统计小区居民的出生年月，大家填的格式不统一：有人写 `199808`（6 位），有人只写 `9808`（4 位）。请统一整理成 `年年年年-月月`。

只写了年份后两位的，规则是：**小于 22 按 20 开头，其余按 19 开头**。

- 输入：一个 4 位或 6 位的合法年月，保证在 1000 年 1 月到 2021 年 12 月之间
- 输出：`yyyy-mm`

自测例（非官方样例）：

| 输入 | 输出 | 说明 |
|---|---|---|
| 199808 | 1998-08 | 6 位，年份现成 |
| 9808 | 1998-08 | 4 位，98 >= 22，补 19 |
| 2108 | 2021-08 | 4 位，21 < 22，补 20 |
| 0508 | 2005-08 | 4 位，带前导 0 |

## 二、我的代码（原样）

```c
#include<stdio.h>
int main(){
    int n,a,b;
    scanf("%d",&n);
    if(n<10000){
        a = n/100;
        b = n%100;
        if(a<22)
            printf("20%02d-%02d",a,b);
        else
            printf("19%d-%02d",a,b);
    }
    else{
        a = n/100;
        b = n%100;
        printf("%d-%02d",a,b);
    }
}
```

## 三、逐段讲

`int n,a,b;`
    把整串年月当成一个十进制整数。这一步埋了一个前提，见第五节的第 4 条。

`if(n<10000)`
    用数值大小区分"4 位"和"6 位"。4 位数最大 9999，6 位数最小 100000；中间的 10000 到 99999 是空洞，题目保证不会出现，所以这个判据成立。

`a = n/100; b = n%100;`
    一对配套运算：`/ 100` 丢掉低两位，留下年；`% 100` 取出低两位，就是月。`199808 / 100 = 1998`，`199808 % 100 = 8`。

内层 `if(a<22) printf("20%02d-%02d",a,b);`
    两位年份小于 22，补成 20xx。`%02d` 保证月份 8 打成 `08`。

内层 `else printf("19%d-%02d",a,b);`
    大于等于 22，补成 19xx。这里用 `%d` 而不是 `%02d`，因为能走到这一支时 `a` 一定在 22 到 99 之间，正好两位，所以结果没错，只是宽度语义不统一。

外层 `else`（6 位）
    年份已经是 4 位，直接输出；月份仍然要 `%02d`。

## 四、分支表

| 输入 | 位数 | n | a = n/100 | b = n%100 | 命中 | 输出 |
|---|---|---|---|---|---|---|
| 199808 | 6 | 199808 | 1998 | 8 | 外层 else | 1998-08 |
| 9808 | 4 | 9808 | 98 | 8 | n<10000，a>=22 | 1998-08 |
| 2108 | 4 | 2108 | 21 | 8 | n<10000，a<22 | 2021-08 |
| 0508 | 4 | 508 | 5 | 8 | n<10000，a<22 | 2005-08 |
| 202112 | 6 | 202112 | 2021 | 12 | 外层 else | 2021-12 |
| 100001 | 6 | 100001 | 1000 | 1 | 外层 else | 1000-01 |

`0508` 这一行值得单独看：`%d` 把前导的 0 吃掉了，`n` 变成 508，位数信息已经丢了。但 `508/100=5`、`508%100=8` 恰好还是"年 05、月 08"，所以结果对。这不是运气好，而是"高位在前、低位固定两位"这个结构决定的：丢掉的高位零对 `/ 100` 和 `% 100` 都没有影响。

## 五、问题与改法

| # | 问题 | 为什么要改 |
|---|---|---|
| 1 | `a` / `b` 没有语义 | 改成 `year` / `month`，读代码不用回头查赋值 |
| 2 | 两个分支里都写了 `a = n/100; b = n%100;` | 拆位和"4 位还是 6 位"无关，提到分支外面写一次 |
| 3 | `"19%d-%02d"` 的宽度靠"a 一定是两位数"撑着 | 改成给年份加世纪再统一输出，宽度问题就消失了 |
| 4 | `n<10000` 用数值大小代替"位数" | 本题 4 位与 6 位之间有空档，所以成立；一旦输入可能是 5 位，就会掉进外层 else 输出错误的年月。靠位数做逻辑时，读成字符串用 `strlen` 最稳 |
| 5 | 没有 `return 0;` | C99 下 main 隐式返回 0，不算错，显式写更清楚 |
| 6 | 输出末尾没有换行 | PTA 一般可以接受，本地终端看会粘住下一行提示符 |

## 六、参考写法

写法 A：数值法，最短（推荐，本题输入范围下完全够用）

```c
#include <stdio.h>

int main(void)
{
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }

    int year = n / 100;
    int month = n % 100;

    if (n < 10000) {                      /* 4 位：只有两位年份 */
        year += (year < 22) ? 2000 : 1900;
    }

    printf("%d-%02d\n", year, month);
    return 0;
}
```

改了什么：

- 两个分支的差别只有"世纪"，把世纪加到 `year` 上，输出就统一成一条 `printf`
- 拆位只写一次
- 变量名换成 `year` / `month`，`%d-%02d` 直接对应"年-月"

写法 B：字符串法，位数信息不丢（输入可能带前导零、或者长度不固定时用）

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[16];
    if (scanf("%15s", s) != 1) {
        return 0;
    }

    int year = 0, month = 0;

    if (strlen(s) == 6) {
        sscanf(s, "%4d%2d", &year, &month);
    } else {
        sscanf(s, "%2d%2d", &year, &month);
        year += (year < 22) ? 2000 : 1900;
    }

    printf("%d-%02d\n", year, month);
    return 0;
}
```

要点：`sscanf` 可以在字符串上按字段宽度取数，`%4d%2d` 就是"前 4 位是年、后 2 位是月"，不用自己算除法和取余。位数由 `strlen` 判断，不会因为前导零而误判。
